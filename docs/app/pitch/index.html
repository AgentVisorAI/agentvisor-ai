Setup

Set up your checkpoint

AgentVisor AI is a policy checkpoint for LLM and tool traffic. Every request runs through identity, quota, size, and safety gates before it leaves your network. So an agent can never call a model or a tool you did not authorize.

1 Where does your agent send its LLM calls?
2 Paste the provider API key. Once.
stored owner-only under ~/.agentvisor/keys/ · never shown again · never leaves your infrastructure
3 Set the policy. Enforced before every call.

The checkpoint runs identity, quota, size, policy, compression and loop detection on every LLM and tool call. Below are the defaults. Tune per session or per principal.

Rate limits tokens & requests

Offline verification

              
$ avctl receipt-verify 84a3f01c….json \
  --public-key-hex 7d2b6085…

              
    
              
    
              
    
                
                
              
    
            
    
            
    Verification is ~30 lines of any language's Ed25519
              library. The signature covers every field of the receipt, and the receipt commits
              to the full event chain. Change anything, anywhere, and verification fails.
    
          
    
        
    

        
    
          
        
    
      
    
    
    

    
    
    
      
    
        
    Data
    
        
    Evidence & export
    
        
    Everything this deployment produces is a plain file on disk in an open,
          industry-standard format. Readable by your SIEM, your auditors, and your customers.
    

        
    
          
    
            
    $ ls -R spool/ data/
    
            
    spool/atif/
├─ 84a3f01c….json         # ATIF v1.7 trajectory. The whole session
├─ 84a3f01c….atif-auth    # provenance sidecar (MAC)
├─ receipts/
│   └─ 84a3f01c….json     # signed receipt (the one you verified)
└─ outbox/                # durable broker hand-off
data/bridge/topics/
├─ agent.tool_call/p0.jsonl   # OCSF events → your SIEM
└─ agent.session/p0.jsonl     # open / seal / receipt events
    
          
    
          
    
            
    
              
    SIEM export
    
              
    Events are OCSF-shaped JSON. The schema your security stack already speaks.
                Stream them to Splunk, Sentinel, or a plain S3 bucket. Nothing phones home.
    
            
    
            
    
              
    Retention
    
              
    Every trajectory, receipt, and archived session is kept as audit evidence until
                you prune it. Move the files anywhere. They stay verifiable offline.
    
            
    
            
    
              
    Audit export
    
              
    A directory of receipts plus one public key is a complete, independently
                verifiable audit package. Including this morning's blocked $8,400.
