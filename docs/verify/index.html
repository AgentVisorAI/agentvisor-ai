How this works

Every session on AgentVisor can end with a receipt: a signed JSON that commits to the exact set of events, tokens, tool calls, and policy decisions that happened. The receipt embeds an Ed25519 public key.

Your browser here runs Web Crypto's Ed25519 verify against the embedded key and the raw signed body. If a single byte changed anywhere, the verification fails. Don't take our word for it — after a green verify, click Now tamper with one byte and watch the same receipt turn red.

The same check runs offline in Node too: node server/scripts/verify-receipt.mjs receipt.json. Same code path, same guarantee.
