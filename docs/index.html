AgentBridge v0.1.0

The audit trail for AI agents.

You put AgentBridge between your app and its model or tools. It records everything the agent does, enforces the limits you set, and hands you a signed receipt at the end of every session that anyone can verify offline — no vendor lock-in, no trust in us.

See it in 60 seconds View on GitHub

What it does

Records what the agent did

Every prompt, tool call, and provider response passes through AgentBridge and lands in an append-only log with timestamps and the caller’s identity. Nothing is inferred or summarised; the log is the raw evidence.

Stops runaways

Set caps on total calls, per-tool calls, spend, and prompt tokens. Detect and cut off loops where the agent keeps trying the same thing. Refusals happen at the gateway, before the model or tool sees the request.

Proves the session stayed in bounds

When a session ends, AgentBridge signs a compact receipt with an Ed25519 key you own. Anyone with the matching public key can verify the receipt offline — the vendor, the customer, an auditor, a subpoena.

Who runs it

  • Security teams that need to know what their AI copilots touched and are tired of relying on the model vendor’s dashboard.
  • Platform / SRE teams who got burned by an agent leaving a database connection open at 3 AM or generating a $4,000 bill on a Sunday.
  • Compliance and legal who need offline-verifiable evidence a customer or regulator can accept without trusting the model vendor’s word.
  • Product teams shipping agents that want to give customers a receipt for each session — a real one, cryptographically signed.

Try it in 60 seconds

Requires Rust (or grab a pre-built binary from the releases page). You’ll be asked one question at a time; a config file is written for you. 

cargo install --path crates/ab-cli --bin abctl
abctl

After the setup wizard finishes, AgentBridge starts on http://127.0.0.1:8484. Point any OpenAI-compatible SDK at that URL as if it were the provider — no code changes. Receipts, events, and trajectories appear under data/.

What it is not

AgentBridge is not an observability dashboard, an analytics tool, or a service you sign up for. It is a small piece of software that runs next to your agent. It writes files to disk. You keep the signing key. If AgentBridge disappeared tomorrow the receipts you already issued would still verify against your key.
